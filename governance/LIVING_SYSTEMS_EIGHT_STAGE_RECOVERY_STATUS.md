## Cross-cutting evidence assets

These tools can support the stages above, but they are not substitutes for field evidence:

- **Meaning Integrity Lab:** 100 unique cases across ten failure classes, 0–2 scoring rubric, risk labels, workbook, study plan, and buyer pitch. The benchmark has not been independently run or validated.
- **Human Judgment Lab:** recommendation-page evaluation operations studio and seeded Consensus Trap simulation. Data are synthetic; no empirical human-rater study has been verified.
- **ARC:** relation-reasoning solvers, toy benchmarks, failure ledgers, and research artifacts. Broad reasoning performance remains unproven.
- **Creation Portal / Image Organism:** actual procedural SVG/Canvas and browser-audio generation code. These are not trained image models and are not connected to ChatGPT's built-in image generator.
- **Animal Recovery Signal Tool:** offline v5/v6/v6.1 record, escalation, and packet tools. These are not diagnostic or treatment systems; real-device QA and health outcomes remain unverified.
- **Veteran Hub / Veteran Mission:** interface and educational artifacts. No live benefits authority or agency integration is established.
- **Creative production archive:** 256-row May 2026 artifact catalog includes a large music-film lane and other creative works. Most large historical sandbox media bytes were not found in the current Library/runtime; metadata alone does not restore them.

## Non-negotiable evidence boundaries

- A file in a repository proves source presence, not runtime behavior.
- A test passing proves only the tested behavior and environment.
- A draft constitution is not a legal instrument or institution.
- A pilot proposal is not an approved pilot.
- A model implementation path is not a trained checkpoint.
- A benchmark dataset is not a benchmark result.
- A successful simulation is not field evidence.
- A catalog entry is not a recoverable file.
- A public deployment URL is not proof of live functionality.
- A social response, agreement, or user relief is not proof of correctness.
