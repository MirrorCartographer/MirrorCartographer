## Status vocabulary
- VERIFIED: implementation and named acceptance test passed.
- CODE-ONLY: source exists; runtime behavior not verified.
- DEPLOYED-UNVERIFIED: deployment exists; relevant live behavior not verified.
- BLOCKED: external authority, access, credential, partner, or dependency required.
- PROPOSED: concept or specification only.
- NOT BUILT: no implementation located.
- PARTIAL: some acceptance criteria pass, others remain open.

## Inventory completion rule
An entry is complete only when repository/path, owner, purpose, implementation status, data boundary, tests, deployment status, dependencies, and next action are recorded. Unknown is a valid status; guessing is not.
