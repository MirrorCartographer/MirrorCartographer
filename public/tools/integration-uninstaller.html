Why this is a guided uninstall

GitHub's API for uninstalling an app requires a JWT belonging to that specific GitHub App. A repository token cannot revoke a different provider's installation. The safe action is to send the account owner to GitHub's authenticated settings UI and let them confirm the exact app.
