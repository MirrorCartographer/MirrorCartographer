# Veteran Commons module map

The public Veteran section is intentionally broader than a benefits list.

### Navigation domains

- Start / desired life
- Benefits and financial security
- Health and readjustment
- Claims and evidence
- Work / VR&E / entrepreneurship
- Housing / accessibility / homelessness prevention
- Education and training
- Family / caregivers / survivors
- Records / identity infrastructure
- Personal Veteran Mission Planner
- Veteran Mission game
- Safety / privacy / governance

### Product direction

The long-term goal is a personal Veteran MC that can maintain a user-controlled, evidence-backed map of service history, goals, capabilities, needs, environmental fit, institutional pathways and outcomes.

It should help the person translate complexity into institutionally legible requests without reducing the person to a rating, diagnosis, employment status or productivity score.
