# Optional Reflection Prompt Library

Use one prompt at a time. Prompts are invitations, not required steps.

## Entry

- What would you like to place on the map?
- What word, image, symbol, color, shape, or texture best represents it?
- What does that representation mean to you?

## Relationship

- What does this element connect to?
- Is the relationship supportive, conflicting, uncertain, or something else?
- Are there two interpretations that should remain separate?

## Spatial

- Where would you place this element relative to the others?
- Is it central, peripheral, near, distant, above, below, inside, or outside?
- Would a different arrangement change the meaning?

## Temporal

- Is this stable, changing, recurring, emerging, or unresolved?
- What has changed since the last time you mapped it?
- What would count as evidence that the map needs revision?

## Integrity

- Which parts are directly observed?
- Which parts are your interpretation?
- Which parts are only a possible assistant hypothesis?
- What is missing or uncertain?

## Closing

- Does this map represent what you intended?
- What should be corrected, removed, or left unresolved?
- Would you like to stop here?
