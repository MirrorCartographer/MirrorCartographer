# LinkedIn Credential Publishing Guide

Only add a credential after its assessment record says **Awarded** and its public verification page exists.

## LinkedIn fields

- **Name:** copy the exact awarded title, including “AI-Assessed Project Credential” and level.
- **Issuing organization:** Mirror Cartographer.
- **Issue date:** use the actual issue date in the credential record.
- **Expiration:** leave blank unless the credential record defines reassessment/expiry.
- **Credential ID:** use the unique ID from the issued record.
- **Credential URL:** use the stable public verification page, not a repository search result.
- **Skills:** select only skills directly supported by the assessment evidence.

## Current issued record

`MC-OR-001 — Founder and Project Originator` is a project recognition record, not a competency certification. It may be listed transparently as a project-issued recognition if desired, but it must not be described as an accredited certification or as proof of independently assessed technical proficiency.

These are credential definitions, not earned awards. Each requires a completed assessment, score, evidence references, and an issued verification record before it belongs in LinkedIn's Licenses & Certifications section.

## Suggested LinkedIn profile placement

- Use **Licenses & Certifications** for awarded project-issued credentials, with the AI-assessment disclosure in the description.
- Use **Projects** for Mirror Cartographer itself and describe your role accurately: founder, originator, product direction, systems design, requirements, research direction, iterative review, and AI-assisted development.
- Use **Featured** for the public project entrance and credential verification pages.
- Do not list planned vendor exams or courses as earned credentials.
