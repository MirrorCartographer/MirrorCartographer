# External Certification Pathways

This guide distinguishes external credentials from Mirror Cartographer's internal competency records. Provider requirements, prices and exam outlines change; verify the official page before registering.

## Priority 1 — GitHub Foundations (GH-900)

**Why it fits:** validates Git/GitHub concepts, repository work, collaboration, project management, modern development practices, privacy/security and community engagement. It is explicitly suitable for GitHub users, not only professional developers.

- Official certification: https://learn.microsoft.com/credentials/certifications/github-foundations/
- GitHub certification overview: https://docs.github.com/en/get-started/showcase-your-expertise-with-github-certifications/about-github-certifications
- Current exam listing observed 9 November 2026: proctored, 100 minutes, USD $99 (regional pricing may differ), no renewal required.
- Preparation: complete the two GitHub Foundations learning paths, review the exam outline, and complete the practice assessment if available in the candidate's profile.
- Readiness evidence: candidate can explain branching, commits, pull requests, reviews, issues, discussions, Actions, permissions, security basics and project workflows.
- Award authority: Microsoft / GitHub certification program after passing the official exam.

**Status:** recommended; not registered; not earned.

## Priority 2 — GitHub Copilot (GH-300)

**Why it fits:** validates responsible use of Copilot in software workflows, including AI capabilities, prompt engineering, testing, privacy and exclusions. It should follow practical exercises, not precede them.

- Official catalog: https://learn.github.com/certifications
- Award authority: GitHub certification program via Pearson VUE / Microsoft Learn.
- Preparation evidence: explain when to accept, modify or reject generated code; test generated changes; identify data/privacy boundaries; preserve human accountability.

**Status:** future option; not registered; not earned.

## Priority 3 — Microsoft Applied Skills

Applied Skills credentials use interactive lab-based assessments to validate scenario-specific tasks with Microsoft technologies. Choose an exact current credential only after selecting a project task that genuinely uses the relevant Microsoft stack.

- Official catalog: https://learn.microsoft.com/en-us/credentials/applied-skills
- Credential overview: https://learn.microsoft.com/en-us/training/student-hub/credentials/

**Status:** catalog-mapping stage; no specific Applied Skills credential selected or earned.

## Priority 4 — IBM SkillsBuild

IBM SkillsBuild offers learning pathways and digital credentials, including AI-related foundational learning. It can be a low-cost entry point, but list only the exact badge title shown in the learner's account after completion.

- Official learning platform: https://skillsbuild.org/
- Verify the current course, assessment and badge criteria before starting.

**Status:** optional foundation route; no badge claimed.

## Digital credential format: Open Badges 3.0

1EdTech Open Badges 3.0 provides a portable structure for describing an achievement, issuer, recipient, criteria, evidence and cryptographic verification. It is a credential format and interoperability standard—not a substitute for a reputable issuer, rigorous assessment or accreditation.

- Standard overview: https://www.1edtech.org/standards/open-badges
- Conformance/certification guide: https://www.imsglobal.org/spec/ob/v3p0/cert/

Mirror Cartographer should begin with transparent, human-readable internal records. It should claim Open Badges compatibility only after the issuer and verification implementation passes the relevant conformance requirements. Certification of a badging platform is distinct from accreditation of the competencies being assessed.

## Candidate preparation order

1. Complete MC internal Evidence Governance assessment to establish a reliable portfolio ledger.
2. Prepare for GitHub Foundations using official learning paths and the published exam outline.
3. Take GH-900 only when practice performance and practical workflow demonstration indicate readiness.
4. Build practical AI-assisted workflow evidence, then consider GH-300.
5. Select a Microsoft Applied Skills lab only when its required technology and scenario align with actual work.
6. Add only completed, provider-issued credentials to the external credentials section of the candidate profile.
