# Human consequences are not browser events
## Mirror Cartographer / experiment contract — 2026-11-16

**Purpose:** prevent a technically working site from becoming another uninteresting museum. The terms *reaction, memory, learning, intelligence, depth, surprise, and psychological* have distinct implementation-level and human-experience meanings. Treating them as interchangeable is a design failure.

| Term | Machine evidence | Human-experience hypothesis | What is NOT established |
|---|---|---|---|
| Reaction | JS state changes; a simulation advances | A change feels consequential, surprising, worth exploring | That any pulse or animation is impressive |
| Memory | A user-authorized field survives navigation | A prior action reappears meaningfully later | That the site remembers or understands the person |
| Learning | A tested rule or parameter changes from feedback | The experience seems to respond differently over time | That hidden model weights were trained |
| Psychological | Spatial, rhythmic, and metaphorical choices affect attention | Visitor may feel curiosity, tension, recognition, or grief | Mind-reading, diagnosis, therapeutic effectiveness |
| Independence | Original code can function offline / without model API | The world feels coherent without an assistant describing it | Consciousness or general intelligence |
| Novelty | A mechanism is new to this project's software | The visitor finds something unexpected that couldn't be reduced to one button | That touchscreens, particles, haptics, or mazes are themselves inventions |

### Source discipline
The surviving historical conversation archive includes several stages; it is not a master specification dating to its earliest exchange. Preserve the original speaker and time. The user's later correction that AI-invented terms were being attributed to her is a critical design constraint. AI-created language can become part of the world if adopted, but not proof the visitor authored it. This public document intentionally does not reproduce private transcripts, medical details, or an API credential.

### Experiment 014 / The Unlived Branch
One chemical orchard runs **two deterministic Gray–Scott worlds**:
- Lived field: receives the visitor's interventions.
- Unlived field: same original seed, recipe changes and elapsed simulation steps, without those interventions.
- The visual glass seam reveals the unacted branch. Its distance from the lived branch is computed from actual concentration-field differences, not supplied by a narrative script.
- Only after a direct seal action is the material difference quantified into a coarse 8×8 field imprint and held in local browser storage. No transcript, identity, GPS, psychological profile, medical record or network endpoint is used.
- Returning to the maze presents a new material object. Explicitly admitting it recomputes the maze's actual corridor graph using a deterministic seed derived from the chemical field. The path connectivity check must pass. The visitor can restart/shift the maze and can clear browser site data.
- The same action has two forms of significance: numerically measurable field divergence, and a possible *human* feeling of the path not taken. Only the first is verified by software tests.

### Gates for every significant upgrade
1. **Causality:** What changes in the world besides styling? State an invariant or observable counterfactual.
2. **Revisitation:** Does it matter next time? If not, don't claim memory.
3. **Autonomy without theater:** Can the world progress independently of touch, without pretending it has a mind?
4. **Consent and reversibility:** Do not secretly profile visitors or silently destroy their saved work.
5. **Sensory reality:** Respect mobile browser audio gestures, reduced motion and hardware haptic limits. Never claim an iOS vibration waveform we cannot produce.
6. **Aesthetic distinction:** Remove headings and buttons and ask whether the environment still possesses its own recognizable grammar.
7. **Proof layers:** Keep numerical tests, browser interaction, GitHub CI, deployed artifact, public HTTP reachability, real iPhone haptic output and human subjective response separate.
8. **Failure recovery:** Reject retrieval-error text in code; guard the public archive and verify all routes.

### Next curiosity
Can a consequence be recognizable *without an explanatory note*? Test the same experience with all labels hidden and with accessible labels intact. Ask the visitor what happened, what differed, and whether it mattered. Treat their account as evidence, not a personality diagnosis.
