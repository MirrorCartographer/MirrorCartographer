# First External Contributor Brief

Mirror Cartographer is inviting a real human contributor to collaborate on a bounded, reviewable improvement.

## Initial task

Improve the GitHub Field Kit with one of the following:
- add pagination for issues and pull requests;
- improve keyboard navigation and screen-reader announcements;
- add rate-limit awareness and a clear retry state;
- add a compact repository comparison view.

## Collaboration rules

- The contributor chooses and performs their own work.
- All authorship and co-author attribution must reflect actual contributions.
- The contributor opens a pull request from their own account or a clearly identified branch.
- Review and tests are required before merge unless the repository owner explicitly chooses a documented exception for a low-risk change.
- The contributor may decline public attribution.
- Do not share credentials or private project files.

A merged collaboration can support a genuine Pair Extraordinaire achievement only if GitHub's co-authorship requirements are met through actual joint work. A fabricated Co-authored-by line is not acceptable.

## How to participate

Open an issue or pull request in the public repository:
