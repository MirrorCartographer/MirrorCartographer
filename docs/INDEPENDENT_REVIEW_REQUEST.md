# Independent technical review request

Mirror Cartographer is seeking an independent technical review of selected public implementations and research artifacts.

## Review objectives

1. Verify that selected artifacts build or run from a clean checkout.
2. Inspect provenance and contribution records for overstatement or missing evidence.
3. Evaluate software quality, security boundaries, test coverage, and reproducibility.
4. Distinguish implemented functionality from design proposals and simulations.
5. Identify the strongest demonstrable technical contributions and the next engineering priorities.

## Candidate review targets

- Public Living Atlas / UI repository: https://github.com/MirrorCartographer/mirror-cartographer-ui
- Public research and provenance repository: https://github.com/MirrorCartographer/MirrorCartographer
- Private evaluation and reflection systems: access can be arranged separately under an agreed confidentiality and privacy boundary.

## Required reviewer output

- Reviewer name and relevant experience.
- Date, commit SHA, environment, and commands used.
- Tests run and exact results.
- Security and privacy findings.
- Reproduction failures and environmental limitations.
- Independent assessment of claims, authorship documentation, and evidence sufficiency.
- Recommendations ranked by severity and impact.

## Independence and conflicts

Reviewers should disclose financial, employment, or personal conflicts. The project will not describe a review as independent unless the reviewer had meaningful freedom to report negative findings and no undisclosed conflict.
