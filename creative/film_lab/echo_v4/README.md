# Echo V4 — film language experiment

A procedural short-film pass built from the bird footage used in the conversation.

## Intent

The previous iterations treated the generated material as separate abstract inserts. V4 changes the grammar: generated scenes are **echoes of the physical footage**. The recurring visual vocabulary is a flock, a threshold, a reflection, and a constellation. The invented material is deliberately sparse so the eye can read the relationship instead of seeing disconnected effects.

## Scene grammar

1. **Reality** — source footage establishes place and movement.
2. **Memory** — a hand-authored flock appears as a visual echo.
3. **Threshold** — a narrow vertical light field becomes a passage rather than an object.
4. **Reality** — the actual birds return.
5. **Reflection** — the flock is mirrored below a waterline.
6. **Reality** — the physical flock takes over again.
7. **Constellation** — the flock resolves into a connected shape.
8. **Reality** — return to the world without explanation.

## Constraints

- No text overlays.
- No data-analysis pipeline.
- No tracking/segmentation requirement.
- Generated forms are authored as a visual grammar, not random particle effects.
- Output remains safe, nonviolent, and suitable for general audiences.

The renderer is intentionally simple enough to mutate: the next pass can change the grammar, not just add effects.
