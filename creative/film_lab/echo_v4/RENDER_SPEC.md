# Echo V4 render specification

**Branch:** `film/echo-next`

**Runtime:** Python + OpenCV/PIL + FFmpeg

**Format:** vertical 512×910, 30 fps, H.264/AAC

## Visual grammar

- Real bird footage is the anchor.
- Generated scenes use only a small vocabulary: flock strokes, concentric orbit, threshold light, reflection line, constellation links.
- Generated elements are cool/neutral and intentionally sparse.
- No words or explanatory graphics.
- The generated flock is hand-authored rather than inferred from the footage.

## Editorial arc

`place → echo → recognition → threshold → place → reflection → release → place`

The goal is not to make the animation look like a separate movie. The goal is to make it feel like a visual thought occurring inside the footage.
