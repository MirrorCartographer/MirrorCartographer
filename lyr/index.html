04 / Reality boundary

What is real now

Implemented in repository: a versioned authority grant, capability-specific policy evaluator, path traversal rejection, and audit receipt structure.

Exercised: 11 local policy checks, including authorized edits, actor mismatch, scope separation, traversal, sensitive data, destructive actions, and external effects.

Not yet connected: an authenticated, always-running LYR orchestrator, execution adapters, persistent server-side memory, and independently verified production deployment.

The system must earn each new capability through executable integration and observable outcomes. This page does not pretend those missing connections already exist.
